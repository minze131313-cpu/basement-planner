# 地下室 3D 空间规划

手机与桌面均可操作的静态 H5，发布在 https://bordy.cn/basement/ 。

## 使用

- 轻点或拖动下方卡片，把储物架、X 型落地晾衣架或公路车放进房间。
- 拖动房间内的陈设摆放；空白处转动视角，双指缩放。可切换俯视视角。
- 选中陈设后调整外廓尺寸、方向、精确位置；储物架支持 2–10 层。
- 撤销 / 重做、复制 / 删除，门口预留区与外廓重叠提示。
- 自动保存到当前浏览器；JSON 导入导出、布局链接分享、当前视角 PNG 导出。

## 空间与模型

室内宽 2.90 m、长 4.00 m。净高暂设 2.67 m，可在房间设置校准。门在短墙，宽 0.80 m，左侧偏移暂设 0.65 m。配电箱与门同墙、在进门右侧；风扇在进门左墙靠后。风管、泡沫与设备细节是示意。

初始示例包含 1 个 120×45×180 cm / 5 层储物架、1 个 145×60×125 cm 晾衣架、4 辆 170×44×100 cm 公路车。48 码指车架尺码，整车外廓应按实车核对。外廓检测是保守的平面矩形检测，不能替代实物间隙测量。

## 本地运行

`python3 -m http.server 8766 --directory dist`，然后打开 `http://localhost:8766/`。

无需构建、账号或后端；全部浏览器资源随站点提供，无运行时 CDN。三维渲染使用本地固定版本 Three.js 0.180.0（MIT），许可见 `dist/vendor/LICENSE`。

发布版本使用合并压缩后的 `dist/planner.js`；原始交互代码为 `dist/app.js`。修改后运行 `npm install`、`npm run build` 重新生成发布脚本。

规划仅保存在浏览器中；服务器不接收布局数据。分享链接使用地址片段携带布局，链接持有人可查看该方案。
